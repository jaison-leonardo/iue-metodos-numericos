# Resolución de PVI usando el Método de Heun

**Ecuación Diferencial:** $y'(t) = y t^3 - 1.1y \Rightarrow f(t,y) = y(t^3 - 1.1)$
**Condición Inicial:** $y(0) = 1$ (es decir, $t_0 = 0, y_0 = 1$)
**Intervalo:** $[0, 2]$
**Tamaño de paso:** $h = 0.5$
**Solución Analítica:** $y = e^{\frac{t^4}{4} - 1.1t}$
**Fórmula de Error:** $\epsilon_t = \left| \frac{y_{real} - y_{num}}{y_{real}} \right| \times 100$

---

## Iteración 1 ($n=1, t_1=0.5$) - *Mostrada en la imagen*
Partimos de $t_0 = 0, y_0 = 1$.
1) $m_0 = f(0, 1) = 1(0^3) - 1.1(1) = -1.1$
2) $y_1^0 = y_0 + m_0 h = 1 + (-1.1)(0.5) = 0.45$
3) $m_1 = f(0.5, y_1^0) = 0.45(0.5^3) - 1.1(0.45) = -0.4388$
4) $\bar{m} = \frac{m_1 + m_0}{2} = \frac{-0.4388 + (-1.1)}{2} = -0.7694$
5) $y_1 = y_0 + \bar{m} h = 1 + (-0.7694)(0.5) = 0.6153$

*   **Analítico:** $y_{analítico}(0.5) = e^{\frac{0.5^4}{4} - 1.1(0.5)} = 0.5860$
*   **Error:** $\epsilon_t = \left| \frac{0.5860 - 0.6153}{0.5860} \right| \times 100 = 5.00\%$

---

## Iteración 2 ($n=2, t_2=1.0$)
Partimos de $t_1 = 0.5, y_1 = 0.6153$.
1) $m_1 = f(0.5, 0.6153) = 0.6153(0.5^3 - 1.1) = 0.6153(-0.975) = -0.5999$
2) $y_2^0 = y_1 + m_1 h = 0.6153 + (-0.5999)(0.5) = 0.6153 - 0.3000 = 0.3154$
3) $m_2 = f(1.0, y_2^0) = 0.3154(1.0^3 - 1.1) = 0.3154(-0.1) = -0.0315$
4) $\bar{m} = \frac{m_2 + m_1}{2} = \frac{-0.0315 - 0.5999}{2} = \frac{-0.6314}{2} = -0.3157$
5) $y_2 = y_1 + \bar{m} h = 0.6153 + (-0.3157)(0.5) = 0.6153 - 0.1579 = 0.4575$

*   **Analítico:** $y_{analítico}(1.0) = e^{\frac{1.0^4}{4} - 1.1(1.0)} = e^{-0.85} = 0.4274$
*   **Error:** $\epsilon_t = \left| \frac{0.4274 - 0.4575}{0.4274} \right| \times 100 = 7.04\%$

---

## Iteración 3 ($n=3, t_3=1.5$)
Partimos de $t_2 = 1.0, y_2 = 0.4575$.
1) $m_2 = f(1.0, 0.4575) = 0.4575(1.0^3 - 1.1) = 0.4575(-0.1) = -0.0458$
2) $y_3^0 = y_2 + m_2 h = 0.4575 + (-0.0458)(0.5) = 0.4575 - 0.0229 = 0.4346$
3) $m_3 = f(1.5, y_3^0) = 0.4346(1.5^3 - 1.1) = 0.4346(2.275) = 0.9887$
4) $\bar{m} = \frac{m_3 + m_2}{2} = \frac{0.9887 + (-0.0458)}{2} = \frac{0.9429}{2} = 0.4715$
5) $y_3 = y_2 + \bar{m} h = 0.4575 + (0.4715)(0.5) = 0.4575 + 0.2358 = 0.6933$

*   **Analítico:** $y_{analítico}(1.5) = e^{\frac{1.5^4}{4} - 1.1(1.5)} = e^{-0.3844} = 0.6809$
*   **Error:** $\epsilon_t = \left| \frac{0.6809 - 0.6933}{0.6809} \right| \times 100 = 1.82\%$

---

## Iteración 4 ($n=4, t_4=2.0$)
Partimos de $t_3 = 1.5, y_3 = 0.6933$.
1) $m_3 = f(1.5, 0.6933) = 0.6933(1.5^3 - 1.1) = 0.6933(2.275) = 1.5773$
2) $y_4^0 = y_3 + m_3 h = 0.6933 + (1.5773)(0.5) = 0.6933 + 0.7887 = 1.4820$
3) $m_4 = f(2.0, y_4^0) = 1.4820(2.0^3 - 1.1) = 1.4820(6.9) = 10.2258$
4) $\bar{m} = \frac{m_4 + m_3}{2} = \frac{10.2258 + 1.5773}{2} = \frac{11.8031}{2} = 5.9016$
5) $y_4 = y_3 + \bar{m} h = 0.6933 + (5.9016)(0.5) = 0.6933 + 2.9508 = 3.6441$

*   **Analítico:** $y_{analítico}(2.0) = e^{\frac{2.0^4}{4} - 1.1(2.0)} = e^{1.8} = 6.0496$
*   **Error:** $\epsilon_t = \left| \frac{6.0496 - 3.6441}{6.0496} \right| \times 100 = 39.76\%$
*(Nota: El error sube drásticamente al final porque la función crece de forma exponencial y el paso $h=0.5$ es demasiado grande para capturar esa curva sin más iteraciones).*
